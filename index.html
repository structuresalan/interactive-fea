Module 1: The Foundation (Hooke's Law)

Every continuous material can be thought of as a complex web of springs. The behavior of a single elastic spring is governed by Hooke's Law:

F = K × Δx

To find how much a structural element deforms under load, we solve for displacement: Δx = F / K

Module 2: The Local Stiffness Matrix

In structural FEA, a 1D element (like a truss member) connects Node 1 and Node 2. When we apply Hooke's law to both nodes simultaneously, we get a matrix equation:

[F1, F2]T = K * [[1, -1], [-1, 1]] * [U1, U2]T

This 2x2 matrix is the Local Stiffness Matrix. It maps the forces at the nodes to the displacements at the nodes.

Module 3: Global Assembly

Structures consist of many elements connected at nodes. If Truss 1 (K1) connects Nodes 1-2, and Truss 2 (K2) connects Nodes 2-3, we must combine their local matrices into a Global Stiffness Matrix.

The shared Node 2 receives stiffness contributions from both elements (K1 + K2). The resulting global matrix is 3x3.

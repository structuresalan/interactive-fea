# Interactive Finite Element Analysis (FEA)

This repository contains two ways to learn the foundations of Finite Element Analysis:

## 1. Web Application (Vercel Ready)
The primary entry point is the web application located in the root directory (`index.html`, `app.js`, `styles.css`). 
This app provides a visual sandbox where you can:
- Read about Hooke's Law.
- Write your own logic in an interactive code editor (in JavaScript).
- See the physical simulation update in real-time.

It is designed to be deployed directly to Vercel as a static site.

## 2. Interactive Jupyter Notebook (`FEA_Interactive_Learning.ipynb`)
For a deeper dive into the mathematics, matrix assembly, and boundary conditions using Python and NumPy, you can run the provided Jupyter Notebook.
